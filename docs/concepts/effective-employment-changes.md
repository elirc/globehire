# Effective employment changes

An employment change is a dated command with intent and evidence, not an edit to the current employment row. It moves from proposed to approved and becomes applicable only on its effective date. Before application it can be cancelled; after application, corrections require a new change.

Offboarding is also a workflow. Final pay, access revocation, and required documents must complete before employment can end. These checkpoints make cross-system integration obligations visible rather than relying on a support checklist.
